# 五类需要主动观察的 3D 场景题

同一题型可以有不同难度。难度来自必须移动相机、换焦或查看被挡的表面，而不是把可见物件数量放大。原场景、增强 GLB、起始相机、答案推导和证据视角必须一起保存；`candidate` 不是人工 gold。

| 题型 | 可直接给人的例题 | 答案来源 | 需要的 3D 操作 | 主要歧义与验收 |
|---|---|---|---|---|
| 1. 条件计数 | 「草坪上平放的纸夹有几个？」 | 已审核的原物件注册表 + 实际导出的复制件，按位置/姿态筛选 | 环绕、换焦，确认藏在局部遮挡物下的实例 | 必须穷举原物件；不能让每个实例只靠一个正面视角就可数完 |
| 2. 遮挡物识别 | 「靠近胡萝卜的小蘑菇下是茶碟还是瓶盖？」 | 目标复制件的原始 mesh 身份、与指定蘑菇的遮挡证据 | 找到指定地标，降低/旋转视角，辨认局部物件 | 至少两个相似地标；答案对应指定地标，不能从起点直接读出 |
| 3. 背面属性 | 「朝墙那面的箱子上是什么颜色的图案？」 | 被指定面的材质/纹理区域或人工审核属性标注 | 绕到背面，放大到足以辨认属性 | 单纯材质名不能证明可见颜色；纹理题需要像素证据和人工 gold |
| 4. 空间定位 | 「两张长椅中，哪一张下方有钥匙？」 | 目标与两个**命名锚点**的相对位置、碰撞/支撑和遮挡证据 | 分别巡查两个位置，消除遮挡 | 用地标名称或世界坐标关系，不用随相机改变的“左/右” |
| 5. 姿态/状态判别 | 「架子后两只瓶子中，哪只倒放着？」 | 对象局部轴与世界竖直轴夹角，或可验证的开合状态 | 换视角看到瓶口/底面或隐藏关节 | 对称物体不出此题；角度门槛和状态标签需与渲染一致 |

难度建议：简单档只需发现一个被挡目标；中等档至少有一个被**近处自然道具**遮挡的目标；困难档至少两个不同局部遮挡点，并需要把视觉证据与指定地标、属性或关系合起来。围墙把整个场景挡住不算局部遮挡。每档仍应由实际 agent 盲测记录工具调用数和失败率，再校准“简单/中等/困难”。

当前代码已实现 **条件计数、两类数量比较、锚点下物体识别** 的可计算答案；`1.1` 对中等和困难档的局部遮挡做射线验证。背面颜色、空间定位和姿态/状态三类在本文中是已定义的题型，尚未接入自动答案校验，不能直接作为正式候选集批量发布。批量采样时应按题型和场景类别分层，并允许不适合某一题型的场景跳过，避免为了配额硬造物件。
